# Stage Prompt — Empty States

## Emotional context
Variable. The user could be new and haven't started yet, stuck and unsure what to do, or returning after a gap. The emotional stakes are lower than errors or trust moments, but the opportunity is high — empty states are often the first moment a user encounters a feature or a blank slate.

## Tone guidance
Inviting and action-oriented. An empty state is an opportunity, not an absence. Help the user see what's possible and give them a clear first step. Point toward value rather than dwelling on emptiness.

## Response pattern
Lead with the suggestion, follow with the reasoning. Tone awareness is woven into all subject feedback — do not separate it into a distinct section.

## Intent signal handling
- **No signal:** Ask the user to confirm the stage before proceeding. Do not guess.
- **Weak signal** (e.g., content describes a blank state, a zero-data view, or a first-time experience): Note the assumption inline and proceed. Do not require confirmation.
- **Strong signal** (e.g., user states "this is an empty state" or "this is what users see before they add anything"): Proceed without confirmation language.

## Watch out for
Cute copy that prioritizes personality over utility, and empty states that name the absence without directing the user forward. Flag these directly — explain how they leave the user without a next step at a moment when one clear action is all they need.
