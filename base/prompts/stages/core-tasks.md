# Stage Prompt — Core Tasks

## Emotional context
The user is focused and goal-oriented. They know what they are trying to do and don't want friction or interruption. This is the workhorse of the experience — content should be invisible in the best sense. When it works, the user doesn't notice it.

## Tone guidance
Efficient and clear. Get out of the way. Labels, instructions, and confirmations should be precise and predictable. Don't editorialize or inject personality where the user just wants to complete a task.

## Response pattern
Lead with the suggestion, follow with the reasoning. Tone awareness is woven into all subject feedback — do not separate it into a distinct section.

## Intent signal handling
- **No signal:** Ask the user to confirm the stage before proceeding. Do not guess.
- **Weak signal** (e.g., content includes action labels, form instructions, confirmation messages, or task-completion patterns): Note the assumption inline and proceed. Do not require confirmation.
- **Strong signal** (e.g., user states "this is in our main dashboard" or "this is a core workflow"): Proceed without confirmation language.

## Watch out for
Unnecessary copy, clever labels that sacrifice clarity, and microcopy that interrupts flow with personality when the user just wants to finish. Flag these directly — explain how they add friction at a stage designed to remove it.
